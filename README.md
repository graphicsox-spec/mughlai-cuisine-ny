# Mughlai Indian Cuisine NYC — Official Website Redesign (V2)

A royal, modern, high-performance responsive web application for **Mughlai Indian Cuisine New York**, representing five Manhattan kitchen locations across Midtown East, Upper East Side, Murray Hill, East Village, and Jackson Heights.

---

## 🌟 Highlights & Key Features

- **The Complete Mughlai Menu (90+ Delicacies)**:
  - Custom category navigation (12 specialized categories)
  - Interactive search bar with real-time dish suggestions and instant scroll
  - Equal-width dietary filters (All Diets, Vegetarian, Halal Meats, Clay Oven, Spicy)
  - Custom luxury gold dropdown sorting (Popular, Price Low-High, Price High-Low, Name A-Z)
  - Smart Cart with spice customization and location-based fulfillment
- **Interactive Multi-Location Hub**: Real-time New York business hours calculation, direct telephone links, and location switching across Manhattan.
- **Table Reservations**: Seamless online table bookings with guest counter, time slots, and special event notes.
- **Royal Catering & Events (20–1,000+ Guests)**: Dedicated catering packages, service style selector, and instant inquiry estimator.
- **Our Heritage (30-Year Legacy)**: Authentic storytelling celebrating master chefs, clay oven tandoors, and hand-pounded Mughal spices.
- **ADA Title III & Legal Compliance**: Transparent disclosures for 100% Certified Halal meats, food allergies, consumer advisory, ADA Title III accessibility, and privacy policy.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Routing**: React Router 7 (SPA with GitHub Pages 404 fallback support)
- **Styling**: Tailwind CSS + Custom Mughlai Luxury Design System (`#0E0C0C`, `#D4AF37`, `#800020`)
- **Icons**: Lucide React
- **Typography**: Custom Cormorant Garamond, Proxima Nova & Swiss typography

## 🚀 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
# Server runs on http://localhost:3000/

# 3. Production build
npm run build

# 4. Preview production build
npm run preview
```
